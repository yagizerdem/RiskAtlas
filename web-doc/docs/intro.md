RiskAtlas proje dokümantasyonuna hoş geldiniz. Bu site, depo kökündeki
`web-doc` klasöründe Docusaurus ile hazırlanır.

## Depo yapısı

| Klasör | İçerik |
| --- | --- |
| `apps/web` | React ve Vite web uygulaması |
| `apps/backend` | Express ve TypeScript backend uygulaması |
| `packages/shared` | Uygulamalar arasında paylaşılan paket |
| `docs` | Mevcut referans dosyaları |
| `web-doc` | Bu dokümantasyon sitesi |
