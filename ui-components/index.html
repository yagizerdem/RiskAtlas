Tailwind ve shadcn/ui

Tailwind CSS 4 ve shadcn/ui bileşenleri dokümantasyon içinde kullanıma hazırdır. Bu örnekte sekmeleri, anahtarı, bildirim düğmesini ve açılır pencereyi deneyebilirsiniz.

RiskAtlas arayüz bileşenleri
shadcn/ui
Tailwind CSS ile düzenlenmiş etkileşimli örnek.

Bileşen kullanımı​

Markdown dosyasını .mdx uzantısıyla kaydedip bileşeni içe aktarın:

import {Button} from '@site/src/components/ui/button';

<Button>Devam et</Button>

React ve TypeScript dosyalarında @/ yolu src/ klasörüne karşılık gelir:

import {Button} from '@/components/ui/button';

export default function Example() {
  return <Button className="w-full sm:w-auto">Devam et</Button>;
}

Kurulu bileşenler​

Resmi base-nova stilinin tüm bileşenleri src/components/ui/ altına kuruldu. Kaynak dosyalarını doğrudan düzenleyebilirsiniz. Bu stil, Base UI altyapısını kullanır; tetikleyici bileşenlerde render={<Button />} biçimi desteklenir.

Tooltip ve toast sağlayıcıları src/theme/Root.tsx içinde site genelinde etkindir. Bildirim göstermek için @/components/ui/toast dosyasından toast içe aktararak toast.add({title: 'İşlem tamamlandı', type: 'success'}) çağrısını kullanın.

Stil ve tema​

  • Tailwind, Docusaurus'un PostCSS aşamasında derlenir.
  • src/ ve docs/ içindeki sınıflar taranır.
  • shadcn renkleri ve köşe yuvarlaklıkları src/css/shadcn.css içindedir.
  • Koyu tema, Docusaurus'un data-theme="dark" ayarını izler; dark: sınıfları çalışır.
  • Tailwind'in genel Preflight sıfırlaması yerine bileşenlere özel temel stiller kullanılır.

Komutlar​

web-doc klasöründe:

npm run ui:add -- button
npm run ui:add -- --all --yes
npm run typecheck
npm run build

Kaynaklar: Tailwind CSS, shadcn/ui.
